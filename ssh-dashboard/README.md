# SSH Dashboard Scripts 📊

Estes scripts servem para instalar e configurar um painel de monitorização (dashboard) via SSH no seu servidor.

### Scripts Disponíveis nesta pasta:
* **ssh-dashboard_x86.sh**: Versão para arquiteturas de PC comuns (Intel/AMD de 64 bits).
* **ssh-dashboard_arm64.sh**: Versão para arquiteturas ARM de 64 bits (ex: Raspberry Pi 4/5).
* **ssh-dashboard_arm64_omv.sh**: Versão otimizada para quem usa o sistema OpenMediaVault (OMV) em dispositivos ARM.
